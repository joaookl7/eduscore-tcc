# EduScore

Sistema web para acompanhamento do desempenho acadêmico.

## Sobre o projeto

O EduScore é uma aplicação web desenvolvida como projeto de Trabalho de Conclusão de Curso (TCC), com o objetivo de auxiliar estudantes no acompanhamento de seu desempenho acadêmico.

O sistema permitirá o cadastro de disciplinas, avaliações e notas, realizando automaticamente o cálculo das médias e apresentando informações sobre o desempenho do estudante por meio de indicadores, gráficos e histórico acadêmico.

## Problema

Estudantes podem ter dificuldade para acompanhar suas notas e seu desempenho acadêmico quando essas informações estão distribuídas entre diferentes locais ou são controladas manualmente.

O EduScore busca centralizar essas informações em uma única aplicação, facilitando o acompanhamento do desempenho acadêmico.

## Objetivo geral

Desenvolver um sistema web para acompanhamento do desempenho acadêmico por meio do registro, organização e análise de notas.

## Objetivos específicos

- Permitir o acesso do usuário por meio de login.
- Permitir o cadastro de disciplinas.
- Permitir o cadastro de avaliações.
- Permitir o registro de notas.
- Calcular automaticamente as médias das disciplinas.
- Informar a situação acadêmica do estudante.
- Apresentar gráficos de desempenho.
- Disponibilizar um histórico acadêmico.
